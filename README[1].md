# NOOR Website

Official website starter for **NOOR — Nonprofit Organization for Opportunities and Relief**.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive design and styling
- `script.js` — navigation and English/Pashto/Dari language switching
- `assets/noor-logo.` — the logo supplied for this website

## Publish with GitHub Pages
1. Open the NOOR-ganization/Noor-website` repository.
2. Upload the files and the `assets` folder to the repository's **root** (not inside another nested folder).
3. If GitHub asks whether to replace existing files, review the names before confirming.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
6. Wait for GitHub Pages to finish publishing. The Pages section will show the live site address.

## Before public launch
Replace the contact placeholder with verified official contact details. Confirm all organizational claims, registration details, leadership, and locations before publishing. The website currently uses general starter text and does not claim unverified programs or registration status.
